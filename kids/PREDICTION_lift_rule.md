# Rule frozen before any new data — still galaxies carry the spin lift (Jaden, 2026-09-25)

Rule: the SPARC-calibrated extra pull (a₀ = 6.6776×10⁻¹¹, lift baked in) applies to spinning galaxies. A still galaxy does not lift, so it carries the lifted weight too: **extra pull_still = extra pull_spin × (1 + L), L = 0.865** (share of a spinning disc's weight carried by rotation; Bottema 1993: σ_R = 0.29V, σ_z = 0.6σ_R, σ_φ = 0.7σ_R → σ²_3D/V² = 0.156 → pressure share 0.135, lift 0.865). One parameter, taken from spiral stellar kinematics, nothing fitted to lensing.
Found on KiDS-1000 red lenses (Brouwer 2021 colour bin 2) as the third of three readings tried there (χ² 311 → 48; best 42) — so KiDS does not count as a test of it.
**Prediction for a new, independent early-type lensing dataset:** g_obs = g_bar + 1.865·√(a₀·g_bar) for still/red/early-type lenses fits within errors and beats the uncorrected spinning form; blue/late-type lenses keep the uncorrected form.
